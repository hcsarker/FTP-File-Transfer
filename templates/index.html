FTP Protocol Implementation

Choose between Connection-Oriented and Connectionless FTP

Connection-Oriented FTP

Uses TCP sockets with acknowledgments and retransmission

  • Reliable file transfer
  • 100-byte chunks with ACKs
  • Timeout and retransmission
  • Guaranteed delivery
Use Connection-Oriented FTP

Connectionless FTP

Uses UDP sockets without acknowledgments

  • Fast file transfer
  • Line-by-line transmission
  • No acknowledgments
  • Best-effort delivery
Use Connectionless FTP

About This Implementation

This project demonstrates two different file transfer protocols:

  • Connection-Oriented: Uses TCP with reliable transmission, acknowledgments, and error recovery
  • Connectionless: Uses UDP with fast, best-effort transmission without guarantees
